# 材料与工艺规格(TC4 粉末 + 20 钢包套)

版本 v1.0(2026-09-09)

> 本文是 ansys-hip-service 的**工程规格基准**:材料规格、验收密度、HIP 工艺曲线,以及
> 供 `material-query` / FEM 内核使用的温度相关性能**文献初值**(含来源与不确定度)。
> 服务侧权威数值表由 `data/materials.yaml`(材料内核读取)维护,本文为其规格与初值来源。
> 单位约定(全服务统一):**mm / MPa / s / ℃**(密度 kg/mm³)。
>
> 相关文档:`docs/api-brief.md`(接口);HIPForm 侧现状分析见 HIPForm 仓库
> `docs/hip-current-issues.zh-CN.md`(默认工况 920℃/100MPa/2h 与本规格的偏差定量)。

## 1. 材料规格

### 1.1 包套:20 钢(GB/T 699 20 钢,近似 AISI 1020)

| 属性 | 室温规格值 | 备注 |
|---|---|---|
| 弹性模量 E | 200 GPa | 即 200000 MPa |
| 屈服强度 σy | 250 MPa | 室温 |
| 抗拉强度 σb | 400 MPa | 室温 |
| 泊松比 ν | 0.30 | |
| 热膨胀系数 α | 1.4×10⁻⁵ /K | |

> ⚠️ **警告:仿真必须补 900℃ 高温力学参数,严禁直接套用室温值。**
> 20 钢 900℃ 屈服强度仅约 **20–30 MPa**(室温的约 1/10)。若用室温 σy=250 MPa 做包套
> 本构,会**高估包套强度/刚度约一个数量级**,导致保温段壁厚减薄与型面演化系统性失真,
> 进而错误约束粉末致密化。高温完整参数(温度相关弹塑性 + 蠕变)见 §3 文献初值表;
> HIPForm 现状(仅两段弹性模量 + Maxwell 粘弹、无塑性/蠕变)的问题分析见
> HIPForm `docs/hip-current-issues.zh-CN.md` §3.2。

### 1.2 粉末:TC4(Ti-6Al-4V,预合金球形粉)

| 属性 | 规格/文献值 | 备注 |
|---|---|---|
| 致密态密度 | 4.43 g/cm³(= 4.43×10⁻⁶ kg/mm³) | |
| 室温屈服强度(烧结/致密态) | 800 MPa | |
| 室温抗拉强度 | 950 MPa | |
| 初始相对密度 D₀ | **0.65** | 装粉态;文献实测参考 64.53%(Jiang 2025) |
| 终态相对密度(验收) | **≥ 0.97** | 工程判定阈值 |
| 模型极限密度 D_limit | 0.995 | Arrhenius 律渐近上限 |

### 1.3 粉末压实模量的密度相关性

多孔压实的瞬时模量按 `E(D) = E_m·D^k` 取值(致密母材模量 × 相对密度幂):
推荐初值 k = 3.0(区间 2.0–3.5,不确定度 ±30%,建议用 `calibrate` 方法反演)。

## 2. 工艺规格与默认工艺曲线

### 2.1 工艺规格

**900℃ / 120 MPa / 保温保压 3 h(10800 s)**。

### 2.2 默认工艺曲线(`config/service.yaml` → `defaults.cycle`,五点)

| 点 | time_s | temperature_c | pressure_mpa | 阶段 |
|---|---|---|---|---|
| 1 | 0 | 20 | 0 | 起点(室温常压) |
| 2 | 3600 | 900 | 120 | 升温加压结束(1 h,20→900℃、0→120 MPa,同步加载) |
| 3 | 14400 | 900 | 120 | **保温保压 3 h(3600→14400 s = 10800 s)** |
| 4 | 16200 | 200 | 10 | 降温段(0.5 h,900→200℃、120→10 MPa) |
| 5 | 18000 | 20 | 0 | 卸温卸压(0.5 h,200→20℃、10→0 MPa) |

- 总历程 **18000 s(5 h)**;相邻控制点间温度/压力线性过渡。
- 该曲线即所有方法的配置链默认值;`config/parts/tc4-demo.yaml` 的 `cycle: {}` 继承本曲线,
  请求内联 `params.cycle` 可再覆盖(三级覆盖见 `docs/api-brief.md` §3)。
- 与 HIPForm 默认(920℃/100 MPa/保温 2 h)的偏差定量分析见
  HIPForm `docs/hip-current-issues.zh-CN.md` §3.1(峰值速率 +70%、等效剂量 +13%,不可抵消)。

### 2.3 Arrhenius 动力学初值(快筛内核用,未标定)

|---|---|---|
| k_ref | 6.0×10⁻⁴ /s | 参考点速率(未标定) |
| T_ref / p_ref | 920℃ / 100 MPa | 动力学参考点(注意:与 §2.1 工艺规格不同,系历史初值) |
| Q(激活能) | 150 kJ/mol | |

> ⚠️ k_ref/Q/n 为**文献量级初值,未经实验标定**;生产决策前应先用 `calibrate` 方法以
> 实验 D-t 数据反演(输出含协方差/置信界)。HIPForm 侧参考点(920℃/100 MPa)若按
> 规格(900℃/120 MPa)重锚,须同步重标 k_ref。

## 4. 文献校核结论

### 4.1 工艺窗口:900℃/120 MPa/3 h 是标准 TC4 HIP 窗口

| 文献 | 工艺 | 结果 |
|---|---|---|
| Xu 等,JMST 2014, 30, 1289–1295 | 优化窗口 900–940℃ / >100 MPa / 3 h;实测点 910℃/120 MPa/3 h | 相对密度 99.71% |
| Guo 等,2024(PMC10934648) | 930℃ / 120 MPa / 3 h | 全致密 |
| Jiang 等,Metals 2025, 15(2), 173 | 扫参 900–970℃ / 120–180 MPa / 3–4 h(基准 940℃/140 MPa/180 min) | 壁厚/几何复杂件局部 71–99%(几何受限) |

结论:规格(900℃/120 MPa/3 h)落在文献验证窗口内,对**简单/中等复杂**几何可达
≥0.97;对深筋、拐角等难充填区,文献显示需更高温度/压力/时长(如 940℃/140 MPa 起),
这正是 `process-window` 扫参(默认温度 880–940℃、压力 100–140 MPa、保温 2–4 h)与
`axisym-mechanical` 局部密度分布要联合回答的问题。文献同时指出:三因子中**温度贡献
最大,压力次之,保温时长最小**。

### 4.2 建模方法:多孔塑性 + 蠕变是文献标准

- 粉末:**Gurson/GTN 型多孔塑性**(K.T. Kim 等针对 HIP 改进)或 **Shima-Oyane 准则**
  (Jiang 2025 采用,屈服面依赖静水应力与 von Mises 等效应力,密度由局部应力状态演化),
  配合高温蠕变(Perzyna 粘塑/Liu 等 2011 耦合模型);
- 包套:温度相关**弹塑性**(von Mises,Jiang 2025 对 304 不锈钢包套取 Marc 材料库参数);
- 界面:**接触非线性**(可张开/滑移 + 摩擦,Jiang 2025 用双线性摩擦模型);
- 几何:**大变形**(NLGEOM)。

阶段 2 的 MAPDL 本构升级(`TB,GURSON`/`TB,SHIMA` + `TB,CREEP` + `CONTA174` +
`NLGEOM,ON`)即按此文献标准执行,API 不变。
